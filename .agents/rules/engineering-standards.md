# Engineering Standards

- No fake functionality or fabricated status.
- Never commit secrets or expose credentials in client bundles/logs.
- Validate and sanitize all external input.
- Preserve working code paths unless replacing with verified behavior.
- Test meaningful changes before claiming completion.
- Do not swallow errors; return safe structured errors.
- Preserve source provenance and license evidence.
- Stop scope creep after acceptance criteria pass.
- Never claim success without direct evidence.
