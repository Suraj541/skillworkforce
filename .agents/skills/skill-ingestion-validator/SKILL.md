# skill-ingestion-validator

## When to use
Use this skill while implementing or reviewing changes related to its control area.

## Inputs
- Feature scope and acceptance criteria
- Relevant code, tests, API routes, and logs

## Procedure
1. Verify current behavior from code and runtime evidence.
2. Apply the control checks for this area before approving a change.
3. Record findings as implemented, verified, partially verified, blocked, or not implemented.
4. Stop and escalate when required safety or evidence thresholds are not met.

## Quality checks
- Findings are evidence-backed.
- No fabricated success states.
- Scope remains aligned to acceptance criteria.

## Output
- Actionable pass/fail findings with required follow-up actions.
