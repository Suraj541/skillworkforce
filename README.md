# skillworkforce

## Run locally
```bash
npm install
npm run dev
```

## Quality checks
```bash
npm run lint
npm run typecheck
npm run build
```

## Database
```bash
# reset local disposable data
npm run db:reset
```

## Scope of this iteration
- Next.js App Router baseline
- SQLite-backed workflow CRUD/validation/run APIs
- n8n-inspired workflow canvas editor (`@xyflow/react`)
- Seeded AI Usage SOP Pack and skill library routes
- Engineering skills in `.agents/skills` and rules in `.agents/rules/engineering-standards.md`
